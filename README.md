# Article Ledger (Android)

রিসার্চ আর্টিকেলের প্রতিটি অথরের কাছ থেকে কত রিয়াল পাওনা, কে কত দিল আর কত বাকি, এই হিসাব রাখার অ্যাপ।

## অ্যাপে যা আছে

- প্রতিটি আর্টিকেলের টাইটেল, জার্নাল, তারিখ আর নোট
- প্রতিটি অথরের নাম, ইমেইল, ইউনিভার্সিটি, ডিপার্টমেন্ট আর তার কাছ থেকে নেওয়ার টাকা
- এক অথর একাধিকবার কিস্তিতে টাকা দিলে প্রতিটি পেমেন্ট আলাদা করে (তারিখ, মাধ্যম, নোটসহ)
- আর্টিকেলের মোট টাকা, মোট পাওয়া আর মোট বাকি নিজে থেকেই হিসাব হয়
- Summary পাতায় সব আর্টিকেল মিলিয়ে মোট হিসাব, কার কাছে সবচেয়ে বেশি বাকি, আর সাম্প্রতিক পেমেন্ট
- Authors পাতায় একজন অথরের সব আর্টিকেলের হিসাব একসাথে (ইমেইল দিয়ে মেলানো হয়)
- বাকি থাকলে এক চাপে অথরকে ইমেইল রিমাইন্ডার
- ব্যাকআপ ফাইল সেভ ও রিস্টোর, আর Excel-এ খোলার মতো CSV রিপোর্ট
- ইন্টারনেট লাগে না, সব ডেটা ফোনেই থাকে

## APK বানানোর উপায় ১: GitHub দিয়ে (কম্পিউটারে কিছু ইনস্টল করতে হবে না)

1. github.com-এ নতুন একটা repository খুলুন (Private রাখতে পারেন)।
2. এই ফোল্ডারের সব ফাইল সেখানে আপলোড করুন। `.github` ফোল্ডারটাও যেন যায়।
3. repository-র **Actions** ট্যাবে গেলে "Build APK" চলতে দেখবেন। ৫ থেকে ১০ মিনিট লাগে।
4. সবুজ টিক এলে সেই রানে ঢুকে নিচে **Artifacts** থেকে `ArticleLedger-apk` ডাউনলোড করুন। এটা একটা zip, ভেতরে `app-debug.apk`।
5. APK ফোনে নিয়ে খুলুন। "Install unknown apps" অনুমতি চাইলে দিন।

## APK বানানোর উপায় ২: Android Studio দিয়ে

1. কম্পিউটারে Android Studio ইনস্টল করুন (ফ্রি)।
2. File > Open দিয়ে এই `ArticleLedger` ফোল্ডারটা খুলুন। প্রথমবার Gradle sync হতে কিছুক্ষণ লাগবে, ইন্টারনেট লাগবে।
3. কোনো ভার্সন আপগ্রেডের কথা বললে Android Studio যা সাজেস্ট করে সেটাই মেনে নিন।
4. Build > Build App Bundle(s) / APK(s) > Build APK(s)।
5. তৈরি হলে `app/build/outputs/apk/debug/app-debug.apk` ফোনে নিয়ে ইনস্টল করুন।

## জরুরি কথা: ব্যাকআপ

ডেটা শুধু ফোনের ভেতরে থাকে। অ্যাপ আনইনস্টল করলে বা "Clear data" দিলে সব মুছে যাবে। তাই মাঝে মাঝে Settings (উপরের গিয়ার আইকন) থেকে **Save backup file** চাপুন আর ফাইলটা Google Drive-এ রাখুন বা নিজেকে ইমেইল করে দিন। নতুন ফোনে অ্যাপ বসিয়ে **Restore from backup** দিলে সব ফিরে আসবে।

## কোড কোথায়

- Android অংশ (ফাইল সেভ, ব্যাক বাটন, ইমেইল): `app/src/main/java/com/bioinventics/articleledger/MainActivity.kt`
